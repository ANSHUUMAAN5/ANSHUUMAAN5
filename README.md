## 📂 Featured Projects

### 🚀 RecallAI — Custom Vector Search Engine for Agentic RAG
`C++` `Python` `LangChain` `Ollama` `Groq`
Full-stack RAG platform for ingesting and querying personal documents, powered by a **custom C++ vector search engine** implementing HNSW, KD-Tree, and brute-force algorithms for benchmarked similarity search. Supports both local (Ollama) and cloud (Groq) LLM inference, with agentic decision-making for dynamic routing based on query context.
🔗 [GitHub](https://github.com/ANSHUUMAAN5/recallai)

### 🎥 Semantic Segmentation for Driving Videos
`PyTorch` `DeepLabV3` `OpenCV`
Engineered a DeepLabV3 segmentation pipeline trained on 701 annotated images across 32 road-scene classes, achieving 63% mean IoU. Streamlined real-time video-stream processing across all classes.
🔗 [GitHub](https://github.com/ANSHUUMAAN5/semantic-segmentation-video)

### 🤟 Real-Time Sign Language Detection
`TensorFlow` `MobileNetV2` `OpenCV` `MediaPipe`
Real-time webcam-based system classifying all 26 letters of the ASL alphabet, translating gestures into text via a trained 26-class pipeline, evaluated on precision/recall.
🔗 [GitHub](https://github.com/ANSHUUMAAN5/Sign-Language-Detection-Project_ASL)

### 📊 ONGC Inventory Forecasting
`Pandas` `Facebook Prophet` `Time Series`
Built a full-stack AI/ML forecasting app to predict oilfield inventory consumption across 801 real items, generating 6-month demand forecasts, alongside an SAP ABAP-based enterprise workflow system with audit-trail logging and role-based access control.

### 💬 Mental Health Tracker
